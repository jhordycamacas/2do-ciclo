#  Descripción General

Este repositorio reúne múltiples proyectos desarrollados principalmente en Java utilizando NetBeans y Maven. Los ejercicios abarcan temas de:

- Estructuras de datos
- Programación orientada a objetos
- Manejo de archivos
- Bases de datos
- Pilas, colas y listas
- Árboles y AVL
- Matrices
- Algoritmos matemáticos
- Ejercicios prácticos de lógica

El objetivo principal del repositorio es servir como respaldo académico y evidencia del progreso en programación y resolución de problemas.

#  Cómo Ejecutar los Proyectos

## NetBeans
1. Abrir NetBeans.
2. Seleccionar “Abrir Proyecto”.
3. Elegir la carpeta del proyecto.
4. Ejecutar el archivo principal.

## Maven

```bash
mvn clean install
```
